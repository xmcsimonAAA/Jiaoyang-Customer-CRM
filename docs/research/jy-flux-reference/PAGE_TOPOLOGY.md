# Flux Reference Page Topology

1. Olive outer canvas: full-viewport background around the app shell.
2. Dark navigation rail: brand, primary workspace links, and a lime upgrade/help panel.
3. Light-gray dashboard workspace: user header, search affordance, date scope, and page title.
4. White metric cards: compact health-style components mapped to customer pipeline, next actions, and progress targets.
5. Dark analysis card: one focused high-contrast module mapped to confirmed participation amount and batch progress.
6. Responsive bottom dock: mobile shortcut actions already present in the customer system.

Layout uses a fixed-width dark rail plus a fluid content area on desktop, with an app shell border and large corner radius. All sections are flow content except the mobile action dock.
